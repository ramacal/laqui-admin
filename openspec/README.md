# OpenSpec

Este directorio contiene el flujo SDD activo para el proyecto greenfield.

## Convención

- `openspec/specs/` contiene la fuente principal de especificaciones.
- `openspec/changes/` contiene cambios activos.
- `openspec/changes/archive/` conserva cambios archivados.

## Nota

El material base de workflow SDD fue tomado como referencia desde `Gentleman-Programming/gentle-ai`, pero esta configuración está adaptada al dominio de este proyecto.
