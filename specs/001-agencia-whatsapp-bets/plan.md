# Implementation Plan: Agencia WhatsApp Bets

## Goal

Construir un MVP mobile-first para captura guiada de jugadas por agencia con persistencia de clientes, órdenes, comprobantes y calendario provincial de Quiniela.

## Phases

1. Definir modelo Prisma greenfield.
2. Scaffold Next.js + TypeScript + Tailwind.
3. Implementar dominio de provincia, agency y calendario.
4. Implementar flujo público de Quiniela.
5. Implementar Quini 6 y Loto Plus.
6. Implementar comprobantes y backoffice mínimo.
